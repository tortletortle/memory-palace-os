# Changelog V1.1.0

- Added deterministic knowledge-to-space compilation from extracted concepts and relations.
- Added semantic room types: gallery, library, threshold, corridor, workshop and garden.
- Added graph-aware room ordering and force-directed concept placement within rooms.
- Added procedural room walls, door openings, connectors and room-specific props.
- Added spatial architecture validator and overlap diagnostics.
- Added `POST /api/palaces/compile` to understand, compile, validate and persist a palace in one request.
- Added room navigation and architecture metrics to the UI.
- Added 18-concept layout comparison and 40-concept stress smoke benchmark.
- Added frontend DOM-selector contract tests; fixed a stale preview selector.
- Preserved V1.0 editing, recall, persistence and previous cognition/transfer engines.
