# V0.4 鲁棒性实验报告

## 实验协议

预实验240次（12种子×4场景×5策略）；留出1920次（64新种子×6场景×5策略），共2160次模拟。两轮之间未更改算法参数。留出新增环境漂移和语义混淆。每次24知识点、42天、336次训练、128次额外独立匹配校准探针（所有策略成本相同，仅自适应策略使用观测）。配对随机数；7/28天延迟测试没有反馈，互不更新。决策不读取真实潜在成本。
主指标为28天无提示回忆；预设非劣效门槛为相对固定策略的95%区间下界≥−2个百分点；强视觉干扰有提示回忆改善下界>0。原始JSON含未调整的配对t区间。本报告另计算六主比较Bonferroni同时区间（t临界值 2.7241）。

## 结论与限制

- 高成本场景，自适应较V0.3减少改造（0.53 vs 3.03），无提示回忆提升1.89个百分点；相对仅先验贝叶斯提升1.24个百分点。
- 强视觉干扰提示回忆较固定提升5.21个百分点，但低于V0.3约1.17个百分点（未校正比较）。不能全面替换旧策略。
- 环境漂移、语义混淆相对固定有负向主指标差值；语义混淆未必源于视觉重叠，决策存在因果归因风险。
- 强视觉依赖、混合和语义混淆场景，双记忆Brier较差。强制有提示概率不低于无提示概率并不适合所有模拟学习者。
- 成本后验是自报匹配任务表现损失代理，不是独立视觉潜变量的真实测量；恢复常数固定14天，采用当前干扰值近似历史负荷，决策使用记忆后验均值与独立成本概率近似。模拟校准额外128探针，不是免费提升。
- 64个留出种子不是1920个独立真人，种子跨场景复用；新增两个手工机制不等于外部验证。未校准真人数据，次级区间不作确认性推断。
- 57项测试通过（45旧+12新），数学与冲突评测63+200+14全部通过。真实模型供应商、三维前端、自动场景版本迁移仍未验证或实现。
