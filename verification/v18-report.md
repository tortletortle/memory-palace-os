# Memory Palace OS V1.8.0 — 研发与验收报告

## 目标与实现边界
基于 V1.7.0 交付源码继续开发，保留八种专用实验模板、三维宫殿、独立测评和复习计划。新建确定性、证据约束的公式编译与数值运行模块。此次选择优先实现安全编译器，而非直接接入大模型生成任意方程和代码；不声称已经实现通用 AI 自动物理建模。

## 新增功能
1. 证据抽取：从已保存锚点的独立等式子句直接提取公式，保留原文，拒绝无法解析的等式。支持最多 6 条显式等式和 8 个输入。
2. AST 解释器：支持四则运算、幂、括号、exp、sqrt、自然对数、绝对值、正弦/余弦（弧度）及 e/pi 常量。限制 token、嵌套、数值范围、幂指数。无 eval、无动态代码生成。
3. 依赖图：检测重复输出、自引用、循环，确定拓扑计算顺序，输入来自未被等式定义的依赖变量。保留所有计算输出。
4. 显式约束：解析最多 12 条 `变量 比较符 常数` 子句，检查未声明变量、常量边界矛盾，对输入及每个计算输出执行约束。未实现完整可满足性判定；不解析自然语言条件。
5. 参数扫描：同一解释器计算 2–81 个等距采样点，对失败点返回空输出及原因；前端 SVG 曲线不会跨越已知无定义采样点。有限采样可能遗漏间隔内的奇点。
6. 宫殿集成：独立页面 `simulation.html` 从工作区/锚点链接进入；支持查看原文、拓扑顺序、条件与数值、双轴参数选择。GET 编译和 POST 执行/扫描接口基于服务器保存的锚点，无学习数据写入；证据变化使旧 revision 失效。

## 可复现示例
- 匀加速：`v=v0+a*t；s=v0*t+0.5*a*t^2；t>=0。`，a=2、t=3、v0=1，输出 v=7、s=12。
- 电路：`P=U*I；U=I*R。`，I=2、R=4，自动排序 U=8、P=16。
- 衰减：`y=exp(-lambda*t)。`，lambda=2、t=0.5，y≈0.3678794412。
- 无定义点：`y=1/x。`，扫描 -2 到 2 共 5 个点，输出 -0.5,-1,null,1,0.5。

## 验证结果
- V1.7 基线 153 项继承测试 + V1.8 9 项新增测试 = 162/162 通过，失败 0。
- 100 组固定种子随机输入；每组分别对照运动学两个输出、串联电路功率、动能，共 400 个数值断言，误差阈值 1e-9，均通过。这里只是数学数值对照，不是外部教材数据集或学习效果实验。
- 覆盖拓扑顺序、运算优先级、显式约束、矛盾与循环、注入字符、歧义语法、复杂度限额、除零及非法输入、数值溢出、证据版本失效、曲线断点、API 非修改性、静态页面资源与 DOM 契约。
- 完整 TypeScript：`npm run typecheck -- --typeRoots /opt/nvm/versions/node/v22.16.0/lib/node_modules/ts-node/node_modules/@types` 通过（使用环境已有 Node 类型；本地安装项目 devDependencies 后可直接 `npm run typecheck`）。
- 前端 JS 语法检查：通过。
- HTTP 真实服务创建宫殿、编译、执行、扫描、错误状态码与静态文件访问：通过。
- 真实 Chromium/Playwright 验收：请求本地 URL 被 `ERR_BLOCKED_BY_ADMINISTRATOR` 拒绝，未完成 DOM/UI 交互及移动端视觉验收。无已验证的页面截图，也未执行 WebGL 验收。

## 限制与下一阶段
- 不自动判断公式或教材真伪、完整物理适用性、单位一致性、因果方向；用户必须核对公式及条件。
- 只接受受限显式代数关系，不能执行任意程序、隐式方程、微分方程、状态转移或通用物理仿真。不能把参数曲线视为时间积分。
- 连续字母默认单个变量，连续大写拒绝以减少隐式乘法误读；并非完备数学语言。默认输入值 1，可能需要按原文条件调整。离线教材拆句可能分割多等式或小数，因此多等式示例建议手动填写锚点原文。
- 尚未连接真实大模型来生成变量意义、单位、适用条件或场景；未嵌入三维实时交互机关，未开展真人学习效果实验。
- 下一步优先尝试“AI 提案—证据校验—人工确认—安全执行”管道与单位约束、状态机和可验证的三维视觉映射。保留拒绝生成机制。
