# Memory Palace OS V0.8 — 技能发现与负迁移评测报告

## 本版实现

- 确定性知识特征提取器：从文本中抽取十类记忆结构特征，并保留触发规则证据。
- 跨领域技能策略发现：将提取结果映射到已有技能基因库，生成多个受预算约束的候选策略。
- 依赖闭包校验：候选策略必须满足技能依赖图约束。
- 负迁移检测：比较技能在源领域与目标领域的效用差；样本不足或损害幅度不足时不报警。
- 独立规则基准：六个学科各一条人工编写的留出样例，重复40轮检查确定性与稳定性。

## 重要方法学限制

本轮40轮重复不是40个独立随机种子。特征提取和策略排序均为确定性算法，重复运行只验证可重复性，不能用于推断统计显著性或泛化性能。六条输入是人工编写的规则测试样例，不是外部数据集，也不是经专家标注的人类学习数据。

当前特征抽取是词典/正则规则，不是语义理解模型。域分类、特征覆盖和策略选择结果只能视为候选建议；低置信度时必须让用户确认。负迁移检测函数需要外部真实或模拟的源/目标领域效用观测，本轮三个案例是人工构造的算法单元测试输入，不是实测迁移结果。
