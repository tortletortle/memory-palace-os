# Memory Palace OS V1.6.0 — 独立知识回忆与迁移测评

## 研发基线与决策
基于实际 V1.5.0 源码增量开发，不改写原有空间编译、MMG 或默认固定间隔策略。V1.5 的空间定位证据不能作为独立语义回忆分数。V1.6 引入一个独立、可追溯的自评测量通道；暂不开展基于未经校准自评分数的自动更新或策略切换。

## 实现
- `src/spatial/knowledge-assessment.ts`：独立回忆题生成、人工迁移题库、发题、锁定作答、揭示参考、锁定自评、统计。发题接口不返回未提交题目的参考答案；提交相同答案重试幂等，修改已锁定答案/评分拒绝；跨宫殿查询隔离。已有尝试快照不因宫殿更新而改变，新迁移题需匹配当前知识源修订哈希。
- `src/store.ts`：新增可选 assessmentAttempts 与 transferItems，兼容旧状态；事务序列化与原子写入沿用 V1.5。
- `src/server.ts`：添加独立测评 API；不改变旧 API。
- `public/assessment.html` / `.js`：无 Three.js 依赖的页面，独立回忆、人工出题、提交后揭示、四级自评、待评分恢复、数据导出。主页面导航链接。
- `test/v16-knowledge-assessment.test.ts`：新增五组测试，覆盖发题不含答案、锁定与幂等、无实质参考时拒绝出题、重复题与明显泄漏拒绝、版本失效与旧快照、首次与重复表现及缺失分数、HTTP 和 DOM 契约。

## 指标定义
每种测评独立统计已发题数、已提交数、已评分数、未评分数、不确定数及正确/部分/错误。严格正确率 = correct / (correct + partial + missed)，分母为零时返回 null。首次成绩按题目版本首次提交统计，不用重复正确答案覆盖首次不确定或未评分。原始记录保留题目版本、时间戳和评分来源。没有真实用户时不报告学习准确率。

## 限制
自评不是独立阅卷；题库由用户或教师人工编写，不能自动验证题目难度、答案完整性或真实迁移。简单的答案泄漏检查不是语义验证。自学环境并非考试防作弊系统；用户仍可阅读其它 API 和此前作答记录。知识源版本变更后统计含历史版本，不是当前版本唯一掌握率。尚无真人效应实验、独立验证评分器或依据独立回忆的自适应策略选择。V1.5 的调度策略保持原样。

## 后续
先建立教师审核的陌生题集和盲评规则，测量不同学习策略在延迟知识回忆和迁移上的效果；再考虑将经校准的独立回忆证据接入复习规划器。
