# Memory Palace OS V1.7.0 — 动态知识实验台研发报告

## 本轮范围
基于 V1.6.0 源码增量开发；保留空间定位、独立知识测评、复习调度等已有模块。建立知识证据到可操作计算模型的首个纵向切片：保存的知识锚点 → 保守模板匹配 → 参数输入 → 确定性计算 → 预测误差反馈。实验台是独立网页，不是三维装置或物理引擎。

## 模板与数学验收
| 模板 | 模型 |
|---|---|
| 欧姆定律 | U=IR |
| 电容电荷 | Q=CU |
| 电功率 | P=UI |
| 与门 | Y=A∧B |
| 与非门 | Y=¬(A∧B) |
| 或门 | Y=A∨B |
| 非门 | Y=¬A |
| 泊松概率 | P(X=k)=λ^k exp(-λ)/k! |

计算测试中三个电学模板各覆盖 11 组数值；四种逻辑门共覆盖 14 个输入组合；泊松模板检查 λ=0 边界、λ=2 k=3 的参考值及四组 λ 的截断概率和。另检查不支持语句、冲突公式、扩展公式、错误标记、输入范围、过期修订、HTTP 生成与运行、持久化不变性和页面契约。该测试集不是独立教材准确率基准。

## 实现
- 知识锚点原文中同时要求学科名称线索和受支持的独立等式；不匹配时明确拒绝；多个公式及部分显式否定标记拒绝。关键词+等式不能证明文本的所有语义与真伪，仍需人工复核。
- 计算函数是代码内固定白名单，不执行用户或模型输入的表达式。输入严格验证，数值输出检查，源内容和模板修订使用 SHA-256 指纹。修订不匹配时拒绝计算。
- 独立实验台显示模型假设、原文与公式，用滑块控制输入，支持先预测后查看结果。实验不写入学习、测评、场景数据，避免误记为掌握度。
- 保留现有 API；新增 `GET /api/palaces/:id/labs/:conceptId` 与 `POST /api/palaces/:id/labs/:conceptId/run`。

## 验收与限制
- 全量自动化测试 153/153 通过（新增 7 项）。
- 完整 TypeScript 静态检查通过：本环境使用已安装的 Node 类型定义；源码包不包含 node_modules。用户可 npm install 安装声明的开发依赖。
- 前端 JS 语法、静态 DOM 契约及 HTTP 集成通过。
- 实际 Chromium 页面访问被管理员策略阻止：net::ERR_BLOCKED_BY_ADMINISTRATOR；没有完成真实浏览器或 WebGL E2E，无可确认截图。
- 尚无真实学习实验，无新远程模型调用，也没有任意公式自动求解、自动 3D 装置生成或物理模拟。仅支持八个模板与有限公式写法，不能保证真正教材语义正确。
- 预测误差仅为当次计算反馈，没有持久化，不进入忘却模型或独立测评。

## 下一步建议
建立可审核的场景 DSL（变量、约束、输入、状态、转移、可视化绑定），把 AI 作为候选生成器；符号/数值/边界验证和独立留出反例共同决定接受或拒绝，而不是直接执行模型生成代码。之后将通过验证的装置绑定到三维房间中的物体，并独立验证学习迁移效果。
